# Notebook 05 — Evaluation Artifact Recovery and Provenance

## Purpose

This note preserves the provenance incident discovered after Notebook 05 completed: the evaluation notebook had executed successfully and reported reusable outputs, but those generated `results/evaluation/` and `figures/evaluation/` artifacts had not been committed to GitHub.

The issue was a **repository-persistence discrepancy, not an experimental-result discrepancy**. The frozen Notebook 05 metrics, decision register, and project context were already mutually consistent.

## What was missing

The missing repository outputs included the canonical Notebook 05 evidence, analysis, and presentation figures generated by `notebooks/05_evaluation_&_scaling.ipynb`, including:

- `results/evaluation/evidence/validation_history_canonical.csv`
- `results/evaluation/evidence/validation_history_ingestion_audit.json`
- `results/evaluation/evidence/final_test_stream_audit.json`
- the analysis CSV/JSON outputs under `results/evaluation/analysis/`
- the figures under `figures/evaluation/`

## Fail-closed recovery rule

The project explicitly rejected hand-reconstructing the missing artifacts from rounded summary values. The recovery order was:

1. prefer exact original artifact bytes when available;
2. otherwise deterministically re-execute Notebook 05 from frozen inputs and unchanged protocol;
3. assert the already-frozen validation/test results before accepting regenerated artifacts;
4. record SHA-256 and byte size for every canonical recovered artifact.

This rule was formalized under D-097 and used by the D-096 provenance gate before Notebook 06A continuation was allowed.

## Resolution

The canonical Notebook 05 artifact set was recovered and committed under:

- `results/evaluation/evidence/`
- `results/evaluation/analysis/`
- `figures/evaluation/`

The content-addressed manifest is:

- `results/evaluation/artifact_manifest_sha256.json`

The deterministic recovery rerun reproduced the frozen Notebook 05 quantitative evidence. Any official-test re-score performed during artifact recovery was treated strictly as deterministic re-measurement of already-selected frozen checkpoints, not as a new model-selection or tuning pass.

## Why this record is retained

The incident is useful project provenance. A fail-closed evidence gate exposed a real retention gap before exploratory continuation could depend on incomplete repository state. The correction strengthened the project by making the Notebook 05 evidence content-addressed and auditable.

The issue is **closed**. Notebook 05 remains the frozen equal-budget A/B/C experiment, and the later Notebook 06A extension remains separate.
